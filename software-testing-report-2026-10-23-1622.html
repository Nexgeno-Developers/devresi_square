15. Final Status

Needs Fixes and Retesting

Recommendation

The public pricing page does list the active landlord plan, and both prices come from that plan record. Landlord Basic is £29.00 per month and £290.00 per year. The Annual control updates the card, the add-ons, and the card’s Start Free Trial link. Register then shows Landlord Basic at £290.00/year. Inactive and non-landlord plans stay off the card list. A guest can open the page from the home navigation without signing in.

Fix BUG-001 before treating FT-002 as accepted. A visitor who selects Annual and then uses the lower “Start 7-Day Free Trial” button is sent to monthly billing while the card still shows the annual price. Retest that button on both cycles, and retest the card link so the annual path still opens £290.00/year.

Also correct the compare table and the FAQ so they do not name Starter, Growth, Pro, and Business as if they were plan records. One high issue remains open (BUG-001). Two medium issues remain (BUG-002, BUG-003). No critical defect was found. Production deployment was not tested.

16. Testing Limitations

  • Only the local artisan server was available. HTTPS, HSTS, production caching, and production error pages were not tested.
  • The phone check was a 390×844 Chrome viewport, not a physical Android, iPhone, or tablet, and not Firefox, Edge, or Safari.
  • The database held one active landlord plan. A second priced landlord plan was created only inside a rolled-back transaction, so the live page was not rechecked in the browser with two real cards.
  • Feature bullets on the card are chosen in the Blade from the property-limit band (a limit of 3 uses the starter list). They are not a features column. This run did not treat that as a price defect.
  • “Save 2 Months” is fixed text in the Blade. It matches this record (two months of £29.00). A later plan with a different annual amount would still show that badge. That was not failed because the current record matches.
  • WB-009 confirms the formatter. No live plan has a null or zero price, and no live plan uses a currency other than GBP.
  • The layout loads Bootstrap Icons, Font Awesome, and Slick from public CDNs. Offline icon rendering was not tested.
  • Admin editing of plan prices, Stripe checkout, and registration submit were outside FT-002. The register page was opened only to confirm the selected plan and price.

Evidence

  • Page: http://127.0.0.1:8001/pricing — HTTP 200, about 40 KB, 605 ms on the local server.
  • Plan row id 1: monthly_price_minor 2900 → £29.00; annual_price_minor 29000 → £290.00. Card data attributes matched those strings.
  • Annual card link: /register?plan_id=1&billing_cycle=annual&account_type=landlord. Register text: “Selected Plan: Landlord Basic”, “Billing: Annual”, “Price: £290.00/year”.
  • At the same moment the lower link was /register?plan_id=1&billing_cycle=monthly&account_type=landlord.
  • Code: app/Http/Controllers/Frontend/FrontendController.php → pricing(); app/Models/Plan.php → formatMinorPrice(); resources/views/frontend/pricing.blade.php → plan card and setBillingCycle().
