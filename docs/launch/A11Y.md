# Accessibility baseline (Launch Step 43)

Primary flows: login, rent pay, report repair, invite tenant.

## Done

- Skip link on workspace layout (`Skip to content` → `#wrapper`)
- Visible `:focus-visible` rings (teal) on buttons, links, bottom tabs, auth controls
- Auth fields use `<label class="auth-field">` wrapping controls
- Tenant repair photo + description labeled; invite form uses `for`/`id`
- Bottom nav has `aria-label="Tenant phone navigation"`

## Manual keyboard check

1. Tab through login → Email → Password → Remember → Login → Forgot → Sign up
2. Tenant: bottom tabs reachable; Rent Pay / Bank details activate with Enter
3. Maintenance: photo input, textarea, Submit
4. People: Tenancy → Name → Email → Invite

Contrast: ink `#0b1220` on wash `#f4f6f8` / white cards; teal accents on navy for active nav.
