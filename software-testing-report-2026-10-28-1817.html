Software testing report

ResiSquare landlord workspace walkthrough. Local app at http://127.0.0.1:8001, signed in as the trial landlord created earlier today. Focus: dead controls, raw HTML, dead-end flows, alignment, and the two property/repair data formats sharing one database.

1. Executive summary

34% — Critical

Final status: Not Ready. A new landlord with no homes is covered by the property-setup overlay on every workspace page. Behind that overlay, the product still serves the old estate-agent property form, points “Upload Document” at the property list, and fills the new repair form with 115 leftover repair categories whose names are “General maintenance” or “Smell Gas” plus a hash. No page was found rendering CSS or HTML tags as visible text.

Critical defects: none that trap the account with no way out (Later is on the overlay). High defects: 4. Recommendation: stop shipping the old Quick Add form to landlords, scope repair categories to real home areas, and keep the setup overlay off pages that are not property setup.

15. Limitations

  • One landlord trial account with an empty portfolio. Estate-agent, contractor, tenant, and super-admin menus were not clicked.
  • The overlay was left in the session on purpose so later pages could show whether it follows the user. Later was not used as the main path.
  • Clicks that the browser tool did not follow were not recorded as dead buttons. Dead targets in this report are hrefs, required fields with no options, or controls marked hidden in the template.
  • Ctrl+K was visible and was not proven broken.
  • No production data was changed. The local database already contained the hashed repair categories.

16. Recommendation

Do not treat the landlord workspace as one product yet. Restrict the setup overlay, retire Quick Add for this plan, stop listing the shared repair catalogue, and fix the document button. Re-test the same account after those four changes, then walk the same pages with one real property so edit screens can be compared with the columns they save.
