15. Final Status

Final Status

Needs Fixes and Retesting

Recommendation

The landlord trial paywall works end to end when the customer switches to GBP and uses a valid test card. The account is created, the card is saved, the trial is £0.00, the workspace opens, and the billing portal shows Visa 4242. A declined card does not open the workspace, and a signed-out visitor cannot open billing.

Fix before production: lock Checkout to GBP (BUG-001), make the pricing copy match the card collection (BUG-002), keep the OTP error on the code step (BUG-003), and either sell add-ons with Stripe prices or stop advertising them (BUG-004). Retest those four, then run rent card pay and a contractor-invoice card pay with a webhook listener. Production deployment is not recommended on this evidence.

16. Testing Limitations

  • Chrome only. No Firefox, Edge, Safari, or a physical phone.
  • No Stripe CLI listener. Success was confirmed because the browser returned to /admin/billing and the app loaded the Checkout session. A customer who closes the tab before that return was not tested. Portal cancellation was not clicked for that reason.
  • 3D Secure and insufficient-funds cards were not used. Expired OTP and duplicate email were not run.
  • Rent card pay was not run. Open rent invoices exist, and creating a new tenant, tenancy, and invoice was not completed in this run. No existing tenant password was used.
  • Repair card pay is blocked. repair_job_invoices has 0 rows, so there is no invoice to pay. Two local migrations were applied so the payment table and marketplace-acceptance columns exist: 2026_10_23_140000_create_repair_job_payments_table and 2026_10_23_160000_add_marketplace_acceptance_to_contractor_profiles.
  • APP_URL for the server process was http://127.0.0.1:8001 so Stripe could return to this port. The .env file was not edited.
  • Temporary mailbox credentials were deleted after the run. OTP values are not included in this report.
