Login

Login — design notes

Works: Quiet card, clear error (“Login failed” + records message), dismiss on the alert.

  • Fill the Login button — outline orange on white has weak affordance. Solid brand fill, full width. File: login view / auth CSS.
  • Persistent labels — placeholders “Email” / “Password” disappear on type. Use label above field.
  • Contrast — header Login/Register, Remember Me, Forgot password are light grey. Aim 4.5:1.
  • Public chrome — hamburger on an unauthenticated login page is leftover app chrome. Drop it or replace with marketing links.
  • Copy — “Please enter your login and password!” is generic. “Sign in to your landlord account” + sentence-case heading, not LOGIN.
  • Document title is “Backend Dashboard” (UX-002) — change to “Sign in | Resisquare”.

Dashboard

Dashboard — design notes

Works: Role-specific hero, four stats with colour-coded icons, Quick actions, Plan usage bar (3/5).

  • Make metric cards links — they already look like tiles. Properties → properties index, tenancies, repairs, contacts. account.blade.php.
  • Hero height — “LANDLORD WORKSPACE” plus large title plus empty green field. Shrink padding; sentence case; put plan chip in the header, not a second dark box.
  • Do not duplicate destinations — metric “3 properties” and Quick action “View properties” compete. Either clickable metrics or a shorter action row, not both at the same visual weight.
  • Trial ends 03 Sep 2026 shown as if the trial is current (BUG-001). When expired, the chip must read Expired, not Trialing, and the banner must force checkout — visual as well as logic.

Calendar

Calendar — design notes

  • Primary action missing — a diary without “Add event” in the toolbar is unfinished. Place it top-right of the calendar, not buried in a drag-select gesture.
  • Collapse filters when empty — six dropdowns + two dates + Clear/Apply for “No events found” is agency density. Default: collapsed “Filters”, search + Add event visible.
  • Empty state in the grid — move “No events found” into the calendar body with Add event. The left column should not be the only empty message.
  • Toolbar layout — title, arrows, today, month/week/day fight for one row. Standard: title left, view switcher + today + Add event right.
  • Landlord event types should not include Buyer Viewing / Mortgage / Valuation. Locale en-GB. Kill the idle inner scrollbar on the month grid.

Properties workspace

Properties — design notes

Works: Master–detail, orange selected rail, Overview / Occupancy / Operations tabs, search + Ctrl+K, solid Add property.

  • Stat row overflow — wrap the five overview chips or use a 3+2 grid so Reception is never clipped.
  • Occupancy empty — “No Active tenancies found” should be “No tenancy on this property” + Add tenancy (this also surfaces BUG-002 visually).
  • Compliance labels — “Add landlord registration” in title case; same button style as Add EPC.
  • Documents empty — hide Type/date filters until there is at least one file. Make Add New Document the filled primary in that pane (and make it work — BUG-004).
  • Deleted filter in the list chrome is agency leftover unless landlords can soft-delete.

Add property overlay

Overlay — design notes

Works: Three-step model, postcode + Search, selectable result cards, duplicate blocked.

  • Stop clipping the intro — selected-address / results must not cover “Find the property” copy. landlord-overlay layout / CSS.
  • Footer actions — Later is secondary (text or outline left). After a search, primary is choosing a card, not Later on the right.
  • Result meta — “house 240 bed 78 bath EPC G Freehold” needs chips: Type · Beds · Baths · EPC · Tenure. Buckingham Palace as 240-bed is a data joke; still format it.
  • Replace “Chimnie” with “UK property data”. Pin duplicate alerts to the top of the modal. Hide “Test mode: try SW1A…” in production.

Tenancies

Tenancies — design notes

  • Title matches filter — Active filter → “Active tenancies”, not “All Tenancies”.
  • Missing property — N/A is too quiet for a broken let. Use a warning chip “No property linked” + Fix.
  • Slim the create form — Property, tenants, type, rent, dates. Hide Admin To Approve / Accounts To Process from landlords. Cap form width (~720px) instead of stretching.
  • Outline View / Rent Ledger are tight; 8px gap minimum. Prefer one primary View and a overflow for ledger.

Portal, finance, contacts

Portal / Finance / Contacts — design notes

  • Portal invite — if the form is hidden, do not keep the “Invite a tenant” heading. Show a blocker card + Add tenancy. Put View/Edit and Revoke in one row or a kebab.
  • Finance empty — add a primary “Add tenancy” or “Open tenancy #15” so the instruction is actionable. Align with Rent Ledger (UX-021).
  • Add Contact = primary — same as + Add property (black/navy/orange solid). Red is revoke only. Tabs Link/Compliance need stronger contrast. One empty glyph (“Not set”), not blank / dash / comma.

Billing and Stripe

Billing — design notes

  • Replace the two tables with a plan card — plan name, £29/month, property usage 3/5, trial/expiry, Activate. Hide Stripe subscription/price IDs from landlords.
  • One trial message — hero chip or banner, not title + banner + status + dates all repeating Trialing.
  • Checkout currency — lock GBP; default country GB. Plan description must match property_limit (BUG-013).

Repair, documents, profile, 403, notifications

Repair → Notifications — design notes

  • Repair wizard — step indicator (1 of n). Stick Previous/Next under the search. Disable Next until a property is selected. Page title owns hierarchy; “Where is the problem?” becomes the field legend.
  • 403 — keep app shell. Title: “This page is not on the landlord plan.” Buttons: Back to dashboard, View billing. resources/views errors / RestrictLandlordRoutes response.
  • Notifications toolbar — one row: filters + From/To labels + Filter + Clear. Mark all read and Preferences side by side. Empty: “You’re up to date” when unfiltered, not “No notifications match these filters.”
  • Profile: join address parts; label Postcode not ZIP Code. Documents index: either add upload here or drop the implication that this page is only a dump of property files.
