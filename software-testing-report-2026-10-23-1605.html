4. Bug / Issue Report

Bug IDModuleIssueSeverityStatusRecommendation
BUG-001 Registration Confirmed. Homepage Start trial and Register never show the registration form. GET /register redirects to pricing because no active landlord plan exists. The visitor sees “No plan is available to start a trial.” High Open RegistrationController.php → showForm() and entryLandlordPlan() → insert at least one active landlord plan so the redirect branch is not taken. FrontendController.php → pricing() uses the same filter, which is why the pricing page also says no plans are available.
BUG-002 Public copy Confirmed while following the same homepage links. The homepage says “Try ResiSquare free for 7 days.” The pricing FAQ, with no plans loaded, says a 14-day free trial. Low Open landing.blade.php → hero fine print hardcodes 7 days. pricing.blade.php → FAQ falls back to 14 when $plans is empty. Use one trial length, preferably the plan’s trial_days once a plan exists.
