15. Final Status

Final Status: Needs Fixes and Retesting

Recommendation: Super Admin can run the platform: Command Centre, plans, addons, accounts, subscriptions, login-as landlord, and return. Landlord users cannot open SaaS admin routes. Fix Billing & Plan for Super Admin first (do not show Activate Subscription on a customer account; do not 403 after leave). Then add Return to Super Admin on impersonation 403s, and clean the low-severity labels (owner status, All Role, My Statement, registrations Reset). Agency CRM in the Super Admin sidebar is a product choice, not a landlord regression.

16. Testing Limitations

  • Only Chrome via the Cursor browser was used. Firefox, Safari, Edge, and phones were not tested.
  • Extend Trial, Update Plan, addon delete, and registration approve were not submitted.
  • Login as the estate-agent account was not run.
  • Activate Subscription / Stripe checkout was not clicked (would have mutated billing).
  • No numeric performance, public SEO, or destructive security testing.
  • Local HTTP on port 8001, not production HTTPS.
  • First login after credentials landed on /admin/saas/accounts (intended URL), then Command Centre was opened at /admin/dashboard.
