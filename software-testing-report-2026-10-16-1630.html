15. Final status

Final status

Needs Fixes and Retesting

Recommendation

Landlord signup, OTP delivery, Stripe test checkout, billing trial state, property onboarding, tenant invite, and the tenant portal shell work on this host. Mail is the release blocker: messages leave through a personal Gmail address, SPF and DKIM fail, and there is no DMARC. The bounce for rairaihan@outlook.co.uk is a missing mailbox on a domain that is not Microsoft Outlook. Repair submit and tenancy-confirmation notices also need a retest. Super Admin screens, contractor signup, rent-invoice payment, and most CRM notification events were not executed.

Critical/High still open: BUG-001, BUG-002, BUG-003, BUG-004, BUG-005, BUG-006. Retest those before production. This host is already on Stripe test keys, which is appropriate for UAT and is not a live-money sign-off.

16. Testing limitations

  • No Super Admin credentials were available. Interior admin, SMTP screen edits, and platform subscription tools were not opened.
  • Contractor signup was not completed. The temporary mailbox provider rejected the third account request.
  • A rent invoice was never issued, so tenant card payment, the rent webhook, and finance emails were not exercised.
  • About sixty CRM notification events exist in code. Only signup OTP, welcome, and tenant invite were observed in a mailbox.
  • The landlord browser session ended while the tenant invite was completed in a second tab, so later landlord screens were not re-walked.
  • No direct database or server log access. Repair failure is from the UI, not from a log line.
  • Only the Cursor Chromium browser on desktop was used. No mobile viewport pass.
  • Performance numbers were not measured.
  • SMTP dialogue with outlook.co.uk’s MX was slow and responses were delayed, so a clean 550 code was not captured. DNS and the 220 banner were captured.
